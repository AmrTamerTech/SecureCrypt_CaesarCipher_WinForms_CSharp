
# 🔐 Secure Crypt – Caesar Cipher | C# WinForms Project

A simple and user-friendly **Encryption and Decryption desktop application** built with **C# and Windows Forms (WinForms)**.

The application allows users to encrypt and decrypt text using a configurable **Shift Key** based on the Caesar Cipher technique.

---

## ✨ Features

- ✔️ Text encryption using a configurable shift key
- ✔️ Text decryption using the corresponding shift key
- ✔️ Adjustable Shift Key using NumericUpDown controls
- ✔️ Copy encrypted text to clipboard
- ✔️ Copy decrypted text to clipboard
- ✔️ Clear input and output fields
- ✔️ Input validation to prevent empty text processing
- ✔️ Read-only output fields
- ✔️ Simple and user-friendly interface
- ✔️ Light and Dark Mode interface

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/AmrTamerTech/Secure-Crypt-Caesar-Cipher.git
   ```

2. Open the solution in Visual Studio.
3. Build and run the project.
4. Enter the text you want to encrypt or decrypt.
5. Choose your desired Shift Key.
6. Click **Encrypt** or **Decrypt**.
7. Copy the result or clear the fields to start again.

---

## 🔒 About Caesar Cipher

Caesar Cipher is a simple substitution technique that shifts characters by a specified number of positions.

- **Encryption:** Shifts characters forward.
- **Decryption:** Shifts characters backward using the same key.

> Note: This project is developed for learning purposes and is not intended for real-world secure encryption.
